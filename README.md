# The polite scraper

A small Python scraping pipeline for the public [Books to Scrape](https://books.toscrape.com/) practice sandbox. It discovers books from only the first three catalogue pages, fetches the product pages politely, validates the records, and writes JSON output and a run report.

## Target classification

- **Target:** `https://books.toscrape.com/`, which the Week 5 assignment identifies as a public scraping practice sandbox.
- **Why:** the assignment expressly designates this sandbox for learning to scrape.
- **Scope:** the first three catalogue pages only; pagination is followed from the page's own next link.
- **Data:** book title, product URL, displayed price, availability, rating, optional description, source catalogue URL, and fetch timestamp.
- **Robots check:** checked `https://books.toscrape.com/robots.txt` once on 2026-10-22. The server returned HTTP 404; no robots file was found. A missing robots file is not treated as blanket permission.

I will not reuse this code on another site without checking its rules and terms first.

## Run it

Requires Python 3.10 or newer.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
python src\main.py
```

The first run fetches and caches HTML. Later runs read the saved copies and print `CACHE HIT`; cached pages do not incur a network delay. The first catalogue response is saved as `cache/catalogue-page-1.html`. All cache files are excluded from Git.

To intentionally request one made-up URL on the sandbox and verify failure handling:

```powershell
python src\main.py --test-broken-page
```

The deliberate 404 is logged and counted in the report; it is never retried and does not replace any successfully collected book. It only runs when explicitly requested.

## Record schema

Each item in `output/books.json` has the eight raw fields plus the normalized numeric price:

| Field | Type | Meaning |
|---|---|---|
| `title` | string | Book title |
| `product_url` | HTTPS URL | Canonical product page and record identity |
| `price_text` | string | Original displayed price |
| `availability_text` | string | Original availability text |
| `rating_text` | string | Original rating |
| `description` | string or null | Product description, if present |
| `source_page` | HTTPS URL | Catalogue page where the product was discovered |
| `fetched_at` | ISO 8601 string | Time the cached HTML was originally fetched |
| `price_gbp` | number | Normalized price in GBP |

Pydantic validates records before they are written. Invalid extracted records are kept in `output/errors.json` with a reason, never mixed into `books.json`. Re-running replaces the output with the current unique set, so records do not accumulate duplicates.

## Politeness and failure handling

- Identifying `User-Agent` header on every real request. Set `SCRAPER_USER_AGENT` to a value naming your project and linking to your repository before publishing; the default names the scraper and links to the sandbox.
- Ten-second request timeout and at least 500 ms between requests, including retries.
- Only HTTP 200 responses are parsed. A timeout or 5xx response is retried once after a short wait; 403 and 404 are not retried.
- HTML is cached locally; cached reads do not contact the site.
- Product pages are handled independently. A broken page is logged and skipped.
- `output/run-report.json` records start time, duration, fetched pages, cache hits, valid and invalid records, failures, and the URLs/reasons for failures.

## Tests

Run the offline parser and normalization tests without making network requests:

```powershell
python -m unittest discover -s tests -v
```

The tests cover price normalization, relative URL resolution, missing descriptions, duplicate URLs, malformed product HTML, and the no-retry rule for a 404.

## Ethics and limitations

Use an official API when one exists. Never bypass logins, paywalls, or blocks, and collect only what you need. This project is intentionally limited to this practice sandbox and the first three catalogue pages. The initial robots request returned 404, so the scraper does not infer site-wide permission from that absence.

This working directory is a local project, not a published public GitHub repository. Before submission, create/push a public repository and make the seven meaningful stage commits requested by the assignment; those publishing actions are not represented as already complete here.
